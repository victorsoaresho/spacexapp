# 🚀 SpaceX Missions App

Aplicativo em **React Native + Expo** que consome a API pública da SpaceX, lista todas as missões e permite salvar/excluir favoritas localmente.

---

## 📱 Funcionalidades

- Buscar todas as missões da SpaceX
- Visualizar imagem, nome e detalhes de cada missão
- Salvar missões favoritas
- Remover missões salvas
- Visualizar detalhes completos de uma missão

---

## 🛠️ Tecnologias Utilizadas

- [Expo](https://expo.dev/)
- [React Native](https://reactnative.dev/)
- [React Navigation](https://reactnavigation.org/)
- API pública da [SpaceX](https://github.com/r-spacex/SpaceX-API)

---

## 📦 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/spacex-missions-app.git
cd spacex-missions-app
```

### 2. Instale as dependências

```bash
npm install
# ou
yarn
```

### 3. Inicie o projeto com o Expo

```bash
npx expo start
```

### 4. Estrutura de Pastas (sugestão)

```bash
src/
├── components/
│   └── MissionCard.js
├── screens/

│   └── Details.js
├── services/

├── utils/

└── App.js
```
